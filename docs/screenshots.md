# Product map and screenshots

The desktop workspace contains these screens:

| Screen | Purpose |
| --- | --- |
| Overview | Workspace state and recent projects |
| Projects | Create, edit and delete project records |
| Plugins | Show real installed plugin records |
| Agents & MCP | OpenCode runtime and provider boundary |
| Settings | Profile and workspace identity |

Fresh PNG captures from the current desktop build are stored locally in the ignored screenshots directory:

- screenshots/overview.png
- screenshots/projects.png
- screenshots/plugins.png
- screenshots/agents-mcp.png
- screenshots/settings.png

The screenshots are a visual reference only. Empty states are intentional because the app never ships fake user records.
