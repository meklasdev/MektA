# MektA AI Tooling & Inspection API

MektA is optimized for AI agents and LLM code generation.

## Programmatic Project Inspection

Run:

```bash
mekta inspect --json
```

Output includes:
- Complete file-system routes
- Registered components
- Parsed page ASTs
- Real-time diagnostic errors and warnings

This allows AI agents to inspect, repair, and generate MektA code without scraping terminal strings.
